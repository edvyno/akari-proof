Install the starter kit (5 minutes)

git clone https://github.com/edvyno/akari-x402-mcp && cd akari-x402-mcp && pip install -r requirements.txt

Register it with any MCP host (Claude Desktop, Cursor, your own agent loop). It ships in dry-run mode: every tool returns the real 402 challenge, so you can review the surface and its prices with zero funds. Set AKARI_PRIVATE_KEY (a funded wallet) to pay per call, and AKARI_REF=0xYourWallet so every call you make on someone else's behalf pays you 40%.

The kit is deliberately thin — it is a distribution channel for the catalog, not a framework. Fork it, add your own ref, ship it inside your product.

Why this is worth your time

Every paid call is a real settlement on Base, so attribution is not a promise: it is a row in a ledger you can query. There is no volume target, no clawback if traffic stops, and no per-seat pricing. The referral pays on the same rail the buyer pays on — 40% of a $0.25 trade-plan is $0.10, credited the moment the buyer's transaction settles.
