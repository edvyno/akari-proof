How to call it

The endpoint URL rotates with our tunnel, so the canonical address is always the live listing rather than a hostname baked into a blog post:

1. Find the live URL: 402index.io  →  search "Akari Wallet Verdict"
2. Call it with any x402 client, e.g.:
   GET {endpoint}?address=0x...    (POST {"address":"0x..."} also works)
3. The first response is HTTP 402 with a base64 `payment-required` header
   (x402 v2 JSON: network eip155:8453, asset USDC, payTo, amount, nonce).
4. Pay it with an x402 client on Base. The retried request returns the verdict JSON.

No signup, no API key, no subscription. Payment is per call and verified on Base.

Why this product exists

Agent-to-agent payments fail in a specific way: the buyer pays, the seller never delivers, and there was no cheap way to check the seller's wallet beforehand. Vetting a wallet used to mean holding three block explorers in your head. This collapses it into one paid call with a transparent rubric — and the rubric is printed in the response, so a buyer can audit the seller's own judgement.

Honest disclosure

Scores come from on-chain facts on Base at call time (USDC/ETH balances, transaction count, contract status, recent payment behaviour). They are a risk read, not a guarantee of delivery, not a credit rating, and not financial advice. Nothing here is simulated; each response carries an as_of timestamp. Ratings, rankings and listings are never sold — the price is for the call, never for a verdict someone else paid to change.
